# Suraj Construction Company Website

Official website of **Suraj Construction Company**, showcasing the company's infrastructure and construction capabilities, completed and ongoing projects, services, career opportunities, and company information.

## About the Website

The website provides a professional digital presence for Suraj Construction Company and allows visitors to:

* Learn about the company and its services
* Explore completed and ongoing projects
* View project details and achievements
* Learn about the company's capabilities
* Explore career and internship opportunities
* Contact the company for business enquiries

## Technology

The website is built using:

* React
* TypeScript
* Tailwind CSS
* TanStack Start
* HTML5
* CSS3
* JavaScript

## Development

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

### Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd <repository-name>
npm install
```

### Run Locally

Start the development server:

```bash
npm run dev
```

The website will be available at the local development URL provided by the development server.

## Project Structure

```text
src/
├── components/      # Reusable UI components
├── routes/          # Website pages and routes
├── assets/          # Images and other assets
├── styles/          # Global and component styles
└── ...
```

## Production Build

To create a production build:

```bash
npm run build
```

To run the production build locally:

```bash
npm run start
```

## Deployment

The website can be deployed to a suitable hosting platform supporting the project's framework and Node.js environment.
